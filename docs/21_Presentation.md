Слайд 4. Основные функции
Каталог (src/catalog.py):

get_low_stock — товары с низким остатком.

search_advanced — комбинированный поиск.

count_by_category — аналитика по категориям.

Корзина (src/cart.py):

add_to_cart — добавление с проверками.

cart_total — сумма заказа.

Заказы (src/orders.py):

create_order — оформление заказа.

orders_by_client — история клиента.

Аналитика (src/analytics.py):

total_revenue — выручка.

best_selling_product — топ-товар.
