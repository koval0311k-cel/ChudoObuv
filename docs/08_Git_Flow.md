## Схема ветвления

В проекте используется **Git Flow** — модель ветвления, при которой:

- `main` — стабильная версия продукта. В неё попадают только проверенные релизы.
- `develop` — ветка для интеграции новых функций. Основная рабочая ветка.
- `feature/<название>` — ветки для отдельных функций. Создаются от `develop`, после завершения сливаются обратно в `develop`.
- `hotfix/<название>` — ветки для срочных исправлений. Создаются от `main`, после завершения сливаются и в `main`, и в `develop`.
