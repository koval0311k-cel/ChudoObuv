## Какие ошибки были найдены и исправлены

1. **Отсутствие функции `get_low_stock` в `shop.py`.**
   - Симптом: `ImportError: cannot import name 'get_low_stock'`.
   - Исправление: добавлена функция после `is_low_stock`.

2. **Файл `shop.py` не был сохранён после правок.**
   - Симптом: тесты видели старую версию модуля.
   - Исправление: сохранение через Ctrl+S.

3. **Кэш Python (`__pycache__`) держал старую версию модуля.**
   - Симптом: изменения не применялись.
   - Исправление: удалена папка `__pycache__`.
