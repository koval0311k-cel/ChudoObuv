1. Назначение приложения
«СпортТовары» — консольное приложение для управления интернет-магазином спортивных товаров. Позволяет:

просматривать каталог товаров;

искать товары по названию, бренду, категории, цене;

добавлять товары в корзину;

оформлять заказы;

сохранять заказы в файл;

строить аналитику по продажам.

2. Требования
Python 3.10 или выше.

ОС: Windows, Linux или macOS.

Дополнительные пакеты не требуются — только стандартная библиотека Python.

4. Описание пунктов меню
Пункт 1. Показать каталог
Выводит все товары с полями: id, название, категория, бренд, цена, рейтинг, суммарное количество.

Пример:

[1] Кроссовки Run (Обувь, Nike) — 8990.0 руб., рейтинг 4.7, всего 6 шт.
[2] Кеды Classic (Обувь, Adidas) — 7490.0 руб., рейтинг 4.5, всего 3 шт.
Пункт 2. Отфильтровать по категории
Запрашивает категорию и выводит товары этой категории.

Пример:

Введите категорию: Обувь
Кроссовки Run — 8990.0 руб.
Кеды Classic — 7490.0 руб.
Кроссовки Trail — 11990.0 руб.
Доступные категории: Обувь, Одежда, Аксессуары.

Пункт 3. Поиск по названию
Ищет товары по подстроке в названии (без учёта регистра).

Пример:

Введите часть названия: кросс
[1] Кроссовки Run — 8990.0 руб.
[9] Кроссовки Trail — 11990.0 руб.
Пункт 4. Показать товары с низким остатком
Выводит товары, у которых суммарное количество ≤ 3 шт.

Пример:

Товары с низким остатком:
  Кеды Classic — 3 шт.
Пункт 5. Добавить в корзину
Запрашивает id товара, размер и количество. Проверяет:

существует ли товар;

есть ли указанный размер;

достаточно ли товара на складе.

Пример:

Введите id товара: 1
Доступные размеры: [40, 41, 42]
Введите размер: 40
Введите количество: 2
Товар 'Кроссовки Run' добавлен
Если товара недостаточно:

Недостаточно товара. Доступно: 2
Пункт 6. Показать корзину
Выводит содержимое корзины и итоговую сумму.

Пример:

Корзина:
  Кроссовки Run, размер 40, 2 шт. × 8990.0 = 17980.0 руб.
  Футболка Sport, размер M, 1 шт. × 2490.0 = 2490.0 руб.
Итого: 20470.0 руб.
Пункт 7. Оформить заказ
Запрашивает имя клиента, создаёт заказ, уменьшает остатки на складе, очищает корзину.

Пример:

Введите имя клиента: Иванов И.И.
Заказ оформлен:
Заказ №1 от 2026-10-12 15:30
Клиент: Иванов И.И.
  Кроссовки Run, размер 40, 2 шт. × 8990.0 = 17980.0 руб.
Итого: 17980.0 руб.
Пункт 8. Показать все заказы
Выводит список всех оформленных заказов.

Пункт 9. Аналитика
Показывает:

всего заказов;

общую выручку;

среднюю сумму заказа;

самый продаваемый товар.

Пример:

Всего заказов: 3
Общая выручка: 47280.0 руб.
Средняя сумма: 15760.0 руб.
Самый продаваемый: Футболка Sport
Пункт 0. Выход
Сохраняет заказы в data/orders.json и завершает работу.

6. Возможные проблемы
Проблема: русский текст отображается «кракозябрами»
Причина: Windows PowerShell использует старую кодировку.
Решение: выполнить в терминале команду:

chcp 65001
или запускать через VS Code (Ctrl+F5).

Проблема: ModuleNotFoundError: No module named 'src'
Причина: запуск не из корня проекта.
Решение: убедиться, что ты в папке ChudoObuv:

cd C:\Users\Андрей\Desktop\ChudoObuv
python main.py
Проблема: data/products.json не найден
Причина: файл удалён или переименован.
Решение: восстановить файл из репозитория:

git checkout data/products.json
