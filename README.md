# СпортТовары — система управления магазином

Консольное приложение для управления интернет-магазином спортивных товаров. Позволяет вести каталог, искать товары, работать с корзиной, оформлять заказы и строить аналитику по продажам.

---

## Описание

**«СпортТовары»** — учебный проект, реализованный на Python 3.10+. Приложение работает в консоли и предоставляет следующие возможности:

- **Каталог товаров** — просмотр, сортировка, фильтрация по категориям и цене.
- **Поиск** — по названию, бренду, комбинированный поиск.
- **Корзина** — добавление, удаление, изменение количества с проверкой остатков.
- **Заказы** — оформление, сохранение в JSON, история заказов.
- **Аналитика** — выручка, средний чек, топ-товары.

---

## Требования

- **Python** 3.10 или выше.
- **Стандартные библиотеки** Python: `json`, `os`, `datetime`, `unittest`.
- Установка дополнительных пакетов **не требуется**.

## Установка

1. Клонировать репозиторий:
git clone https://github.com/koval0311k-cel/ChudoObuv.git

2. Перейти в папку проекта:
cd ChudoObuv

3. (Опционально) Создать виртуальное окружение:
python -m venv venv
venv\Scripts\activate
source venv/bin/activate

---

## Запуск
python main.py

Откроется меню с пунктами:

- 1 — Показать каталог
- 2 — Отфильтровать по категории
- 3 — Поиск по названию
- 4 — Показать товары с низким остатком
- 5 — Добавить в корзину
- 6 — Показать корзину
- 7 — Оформить заказ
- 8 — Показать все заказы
- 9 — Аналитика
- 0 — Выход
